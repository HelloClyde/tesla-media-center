# GAM4980 Player

入口：应用列表 / 左侧栏 → GAM4980 Player，路由 `/apps/gam4980`。

基于 HelloClyde/BBK9588-gam4980 的固定版本 73b884a056ca0595de1552e6e365138687fb25a1。保留其 GPL-3.0 核心源码和许可，设备相关内存接口改为 WebAssembly 静态缓冲区。运行资源来自该仓库；不附带商业游戏。来源及资源 SHA-256 在 `web/public/gam4980/provenance.json`。

## 操作

- 进入应用先显示服务器游戏库，选择 `.gam` 下载至浏览器后运行（70 字节至 0x1e0000 字节）。播放页也保留打开本机文件的入口。
- 方向键 / Enter / Esc，或触屏方向键、确定和退出；触屏支持长按重复。
- 键盘按钮展开字母数字、菜单、帮助、翻页等按键。
- 暂停/继续、重新启动、四种 LCD 颜色。
- 自动保存游戏存档到当前浏览器，按游戏内容区分。存档不是即时快照，重新打开恢复的是游戏自身存档进度。
- 支持导入/导出 80 KB `.sav`；导入会重新启动游戏。浏览器数据清理会删除本地存档，建议定期导出。
- 隐藏页面或窗口失焦暂停，返回后手动继续；离开应用保存后终止 Worker。

## 构建及验证

仓库包含可直接部署的 core.wasm。重建需要 clang + lld，执行 `python3 tools/gam4980/build.py`。生成的 source.zip 提供完整 C 核心、适配层和构建脚本；解压后可用 `python3 build.py --output ./dist` 单独构建。前端和 Worker 在 TMC 源码中。

`node tools/gam4980/test.mjs` 验证 ROM 初始化、非法长度、120 帧执行、LCD 输出及存档缓冲区。浏览器实测自编 6502 诊断 GAM 的画面、暂停/继续、存档导出/导入、窄屏排版和切页 Worker 释放。生产构建通过。特斯拉实车尚未验证。

原移植核心没有音频输出适配，本版暂不支持声音；不宣称兼容所有 GAM 游戏。

## 手柄

浏览器 Gamepad API：十字键/左摇杆移动，A 确定、B 返回、X 空格、Y 帮助，Select 菜单，Start 暂停/继续，L/R 翻页。摇杆死区为 0.55，斜向取主轴。方向长按 350ms 后每 110ms 重复，其他按键只响应按下沿。页面会显示手柄名称；非标准映射会提示位置可能不同。

断连、隐藏、失焦及切页清理输入；重新连接或恢复时必须先释放按键，避免残留输入。单位测试及浏览器模拟手柄验证了映射、重复、Start 切换、断连和切页清理，尚未使用实体手柄/实车验收。若浏览器限制 API，界面会提示 HTTPS/本机访问要求。

## 服务器游戏库

固定目录为统一数据目录下的 `gam4980/`（Docker 为 `/data/gam4980`），不再读取 `gam4980_path`，也不允许通过配置接口修改。游戏库右上角“上传游戏”支持多选 `.gam`，上传后自动刷新根目录；同名文件拒绝覆盖。支持子目录、当前目录搜索和刷新。服务器只列出文件夹和 `.gam`，非法大小不能启动。列表和下载要求登录，路径穿越及指向目录外的符号链接被拒绝。

Docker 部署使用可写挂载 `-v /opt/tmc/data:/data`，供上传及持久化使用。存档按游戏内容标识保存到服务端 `gam4980/saves/`，浏览器保留备份用于网络失败后的重试；旧浏览器存档首次打开对应游戏时迁移。

本机已复制下载目录里的伏魔记到默认游戏库用于验证；游戏目录已加入 gitignore，不会进入仓库。真实 API 验证了列表选游戏、下载运行和返回游戏库后终止 Worker；后端测试覆盖过滤、登录、文件大小和目录边界。
