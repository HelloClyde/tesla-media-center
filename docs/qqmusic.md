# QQ 音乐

搜索入口收在右上角放大镜中，点击后才展示输入框与结果；回到首页或我的音乐会收起搜索。账号按钮展示会员类型和上游返回的会员等级，账号弹窗可刷新；获取失败显示未知状态。歌曲列表显示 VIP、单独付费、付费播放、普通音质或权益待确认，来自歌曲的播放权限字段，下载付费不当作播放付费。“普通音质”只表示未标记会员播放限制，不保证高音质权限或当前地区可播。

首页使用两张入口卡片：「每日推荐」点开歌曲列表；「猜你喜欢」点击直接播放，临近队尾自动补充推荐批次，下一首到达队尾时等待补充。每批过滤队列中已有歌曲，最多重试三个重复批次，空结果或网络失败保留当前队列并提示重试。接口按批返回而非页码分页，能持续获取新歌曲时即可连续播放；不保证上游无限返回不重复歌曲。切换到搜索、收藏或每日歌单的歌曲后结束电台补充，过期请求不会覆盖新队列。

首页新增独立的「每日推荐」入口（默认展示），与「猜你喜欢」分开，可播放全部并显示实际歌曲数，不硬凑 30 首。适配层使用已登录客户端读取 QQ 音乐桌面首页的「今日私享」歌单 ID，再读取歌单歌曲。实现参考 [QQMusicApi daily 路由](https://github.com/jsososo/QQMusicApi/blob/master/routes/recommend.js)。网页结构变化或账号入口缺失时明确报错，不回退到随机推荐。目前网页可达和离线解析/路由测试通过；本人登录后的每日歌单、与手机端的一致性仍待实测。

「我的音乐」包含收藏歌曲、收藏歌单、自建歌单和最近播放。前三项从当前 QQ / 微信登录账号读取，收藏歌曲/歌单和歌单详情支持分页，点击歌单可进入歌曲列表。自建歌单使用接口返回的完整列表；歌单详情使用歌单 ID，而非目录 ID。

最近播放为**本机记录**：在音频实际开始播放后记录，去重并保留最近 100 首，按账号保存在当前浏览器 localStorage，未登录记录单独保存。不会读取或同步手机 QQ 音乐的云端历史；当前固定版本接口库没有提供该能力。浏览器禁用存储时仅保留当前页面会话记录。

首页提供「猜你喜欢」：QQ 或微信登录成功后自动获取当前账号的推荐歌曲，支持「换一批」和点击播放。上下首使用点击时的推荐列表；刷新推荐不打断当前播放。未登录时显示登录入口，上游无结果或请求失败时显示明确提示。搜索结果保存在独立页签，可以随时回到首页。

侧栏耳机图标进入 QQ 音乐，支持歌曲搜索、分页、播放/暂停、上一首/下一首、进度调整和 QQ 扫码登录。播放列表取自点击歌曲时的搜索结果；离开音乐页面即停止播放。

在「登录 QQ 音乐」中选择「QQ 登录」或「微信登录」，使用对应手机应用扫码并确认授权。切换方式会重新获取二维码，旧二维码轮询停止。请选择平时登录 QQ 音乐的方式，QQ 和微信对应的账号及会员权益可能不同。二维码三分钟后失效，可以刷新。不同浏览器独立登录，退出登录会删除该浏览器的服务端凭据并停止播放。未登录或账号没有对应权益的歌曲可能无法播放，页面会明确提示；不会绕过会员或版权限制。

`POST /api/qqmusic/login` 接受 `{"provider":"qq"}` 或 `{"provider":"wx"}`，省略时仍默认 QQ。状态接口继续按服务端保存的二维码类型轮询，前端不接触账号凭据。

## 部署

- Python 3.10 或以上，安装 `requirement.txt`（新增固定版本 `qqmusic-api-python==0.7.3`）。
- 运行 `python flask_app.py`，前端沿用现有 Vite 代理或生产静态文件。
- `.qqmusic/` 保存每个浏览器的设备信息和加密登录凭据；凭据加密密钥由应用 `secret_key` 派生，不返回前端或配置接口。目录已排除 Git 和 Docker 构建上下文，生产环境需限制目录访问。
- Docker 需要持久登录时，将独立数据卷挂载到 `/root/tesla-media-center/.qqmusic`，同时持久化原有 `config.json`。修改 `secret_key` 或清除浏览器会话后需要重新扫码。
- 音频由浏览器直接请求 QQ 音乐的 HTTPS CDN。服务器需要能访问 QQ 登录和音乐 API，浏览器需要能访问 QQ 音乐 CDN。

使用社区维护的 [QQMusicApi](https://github.com/l-1124/QQMusicApi)，不是腾讯官方开放平台授权集成，上游接口变化可能影响可用性。仅获取账号实际有权播放的音源。

页面顶部可选择标准 MP3 128 kbps、高品质 MP3 320 kbps、无损 FLAC，默认标准音质。选择保存在当前浏览器，下次点击歌曲或切歌时生效，不打断当前播放。浏览器不支持 FLAC 时禁用无损选项。没有对应音源或账号权限时会提示，不会静默降低音质。

## 检查

`python -m unittest discover -s tests -p test_qqmusic.py` 覆盖应用登录校验、参数校验、扫码会话隔离、凭据加密及退出删除。`npm --prefix web run build` 检查前端类型和构建。

真实搜索、二维码获取/轮询以及匿名可播放歌曲可独立验证；扫码成功和会员歌曲播放需使用本人账号完成端到端验证。


### 正在播放与歌词

点击底部歌曲封面或标题可进入正在播放页，返回后保持当前音频播放。唱片、光晕和装饰音柱随播放/暂停状态启停（非音频频谱），遵循减少动态效果设置。通过 `/api/qqmusic/lyrics?mid=...` 获取歌词，支持 LRC 时间戳、偏移、翻译及点击歌词跳转。歌词失败可重试，无歌词时显示提示，不影响播放。


### 2026-09-26 功能补齐与边界

- 播放队列：查看、点播、加入、移除、上移；顺序、列表循环、单曲循环、随机播放。猜你喜欢保持连续推荐模式。
- 收藏与歌单：歌曲菜单和播放页可红心收藏、取消收藏、添加到歌单；我的音乐可新建歌单、自建歌单内移除歌曲。写操作由服务端使用当前账号凭证，并校验目标歌单属于当前账号。已有收藏未加载时，菜单提供显式取消入口，不推断远端收藏状态。
- 内容：排行榜及歌曲、主题歌单搜索、歌手歌曲页、专辑歌曲页；分类搜索包含歌曲、歌手、专辑、歌单、MV、有声。搜索建议采用防抖，本机搜索历史可清除。歌手页当前以歌曲列表为主。
- MV：解析实际 MP4 播放地址，播放时暂停音乐；无可用地址或浏览器不支持时显示错误。热门评论可分页查看，不提供发评论入口。
- 歌词：独立请求逐字 QRC，失败回退 LRC；字号、译文显示、时间偏移保存在本机。没有逐字数据时不模拟逐字时间。
- 音质：增加臻品音质和母带的真实音源请求，仍由上游账号权限与浏览器解码决定。均衡器使用 Web Audio，提供原声、低音、人声、柔和预设；需要音源支持 CORS，不支持时重建原声播放器，避免无声。
- 本机播放恢复：按 QQ 音乐账号保存队列、歌曲和进度，再进入不会自动播放。接入 Media Session 的播放/暂停/切歌/定位，具体车机支持程度需实测。

未完成：手机端历史/队列/进度同步（当前 SDK 无接口）、授权离线下载管理（当前仅有在线播放音源接口）、QQ 原生空间音效解码、完整播客栏目/订阅、歌单改名。不会把本机记录称作手机同步，也不会把普通均衡器称作空间音效。

验证：离线测试覆盖账号隔离、歌单所有权、创建模型、搜索/浏览分页、音源规格、歌词和播放模式。实际匿名接口验证排行榜 46 项、搜索建议、歌手/专辑/歌单/MV 搜索成功。随后歌曲搜索触发上游限流，MV 测试返回无授权地址，因此端到端播放与真实账号写操作仍待验收；没有为测试修改用户真实收藏或歌单。


### 歌手主页、排行榜与空间混响

首页“歌手”入口和歌曲菜单可打开歌手主页，展示头像、地区/流派、简介及歌曲、专辑、MV 三个分页栏目。资料请求独立于歌曲请求，资料失败仍可浏览歌曲。排行榜保留官方分组，详情展示更新时间、期数、曲目总数、排名和当前列表播放。

音效按钮打开均衡器与空间感面板。开启音效后可选择小房间（0.55 秒尾音）或音乐厅（1.6 秒尾音），调整 0–50% 混响强度。采用 Web Audio 双声道卷积和独立干湿声道，左右不同的早期反射与衰减产生空间感。这是立体声空间模拟，不提供 QQ 原生全景声/杜比多声道解码；车机音响听感尚需实测。音源不支持跨域音效时会回到原声播放。


### 多声道空间音效自动降级

空间音效开启时，按 AudioDestinationNode 报告能力尝试 8、6、2 声道；配置或音频图创建失败逐级回退。前左右保留干声，中置合成低增益单声道人声区域（不做声源分离），LFE 为 120Hz 低通，侧/后环绕使用混响及延迟。属于立体声音源合成环绕，不是原生多声道解码。关闭空间效果时恢复双声道输出，关闭音效时恢复原始媒体元素。面板显示实际配置通道并提供强制双声道开关。硬件扬声器路由、车机下混和真实听感仍需实测，API 无法自动确认这些物理结果。
