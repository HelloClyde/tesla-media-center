# QQ 音乐

侧栏耳机图标进入 QQ 音乐，支持歌曲搜索、分页、播放/暂停、上一首/下一首、进度调整和 QQ 扫码登录。播放列表取自点击歌曲时的搜索结果；离开音乐页面即停止播放。

在「登录 QQ 音乐」中获取二维码，使用手机 QQ 扫码并确认授权。二维码三分钟后失效，可以刷新。不同浏览器独立登录，退出登录会删除该浏览器的服务端凭据并停止播放。未登录或账号没有对应权益的歌曲可能无法播放，页面会明确提示；不会绕过会员或版权限制。

## 部署

- Python 3.10 或以上，安装 `requirement.txt`（新增固定版本 `qqmusic-api-python==0.7.3`）。
- 运行 `python flask_app.py`，前端沿用现有 Vite 代理或生产静态文件。
- `.qqmusic/` 保存每个浏览器的设备信息和加密登录凭据；凭据加密密钥由应用 `secret_key` 派生，不返回前端或配置接口。目录已排除 Git 和 Docker 构建上下文，生产环境需限制目录访问。
- Docker 需要持久登录时，将独立数据卷挂载到 `/root/tesla-media-center/.qqmusic`，同时持久化原有 `config.json`。修改 `secret_key` 或清除浏览器会话后需要重新扫码。
- 音频由浏览器直接请求 QQ 音乐的 HTTPS CDN。服务器需要能访问 QQ 登录和音乐 API，浏览器需要能访问 QQ 音乐 CDN。

使用社区维护的 [QQMusicApi](https://github.com/l-1124/QQMusicApi)，不是腾讯官方开放平台授权集成，上游接口变化可能影响可用性。仅获取账号实际有权播放的音源。

页面顶部可选择标准 MP3 128 kbps、高品质 MP3 320 kbps、无损 FLAC，默认标准音质。选择保存在当前浏览器，下次点击歌曲或切歌时生效，不打断当前播放。浏览器不支持 FLAC 时禁用无损选项。没有对应音源或账号权限时会提示，不会静默降低音质。

## 检查

`python -m unittest discover -s tests -p test_qqmusic.py` 覆盖应用登录校验、参数校验、扫码会话隔离、凭据加密及退出删除。`npm --prefix web run build` 检查前端类型和构建。

真实搜索、二维码获取/轮询以及匿名可播放歌曲可独立验证；扫码成功和会员歌曲播放需使用本人账号完成端到端验证。
